6 months

Evangadi — Full-Stack Web Development Bootcamp

Evangadi Network (Intensive Bootcamp)

Completed an intensive 6-month full-stack web development bootcamp at Evangadi Network. The program focused on the MERN stack (MongoDB, Express.js, React, Node.js) and core web technologies (HTML, CSS, JavaScript). During the bootcamp I built multiple full-stack applications, implemented RESTful APIs, worked with authentication and databases (Firebase & MySQL), practiced responsive UI design, and deployed projects to public hosting platforms. The curriculum emphasized hands-on development, version control with Git/GitHub, and collaborative workflows using Agile methodologies.

I continue to grow my portfolio and contribute to open-source and freelance projects to deepen practical skills.
